How CBT Works — Quick Guide

  1. Create a CBT Course — this is separate from regular courses.
  2. Add questions manually via the Question Bank, or bulk-import them from Excel.
  3. Aim for ≥ 20 questions per course so two students rarely get identical tests.
  4. Toggle the module ON in SiteSettings to make it visible to students.
  5. Students take tests via /academics/cbt/ — no login needed.
  6. Results include a fun AI-generated report (toggle in settings) and a retake option.
